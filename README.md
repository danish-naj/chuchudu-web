# ChuChudu — Personal Encrypted File Vault

Decentralized, end-to-end encrypted personal file transfer and vault platform.

- **Frontend**: React + Vite + Tailwind CSS (Brutalist Modern Design)
- **Security**: Client-side AES-256-GCM encryption with PBKDF2 key derivation
- **Storage**: Local hard-drive vault (~/Chuchudu_Vault) + auto-purged cloud transit buffer
- **Architecture**: Zero-Knowledge Privacy Standard

Live at: https://chuchudu.in
